# Física Computacional II — 2026-II

Repositorio del curso **Física Computacional II (FISCOMPII)** de la **Universidad de Santiago de Chile (USACH)**, correspondiente al segundo semestre de 2026.

Este repositorio contiene los distintos **notebooks, ejemplos, ejercicios y actividades** que se desarrollarán durante el curso para la carrera de:

> **Astrofísica con mención en Ciencia de Datos**

---

## Contenido

A lo largo del curso se utilizarán principalmente herramientas de programación científica en **Python** para abordar diferentes problemas computacionales relacionados con física y astrofísica.

El repositorio incluirá:

- Notebooks de clases
- Ejemplos de código
- Ejercicios prácticos
- Actividades computacionales
- Visualización y análisis de datos
- Tareas y material complementario

---
